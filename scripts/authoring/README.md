# Materiał autorski partii 0.7 i 0.8

Pliki batch08 korzystają ze wspólnych funkcji autorskich batch07. Pliki Python zawierają ręcznie napisane zadania, nie generator losowych wariantów. Służyły do jednorazowego utworzenia paczek na bazie poprzednich wersji. Nie uruchamiaj ich na bieżącej bazie: istniejące pliki są chronione asercjami.

Autorytatywną treścią po przeglądzie są pliki `content/**/*.yaml`. Mapowania celów i źródła części zadań dopracowano w YAML po pierwszym zapisie. Dalsze poprawki wprowadzaj w YAML i uruchom walidację/testy. Skrypty autorskie nie są częścią builda ani kodu dostarczanego do przeglądarki.
